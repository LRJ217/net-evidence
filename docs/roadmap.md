## 外部评审建议的后续取舍

- 已落实：字面量 IP 的 DNS 跳过状态、连接重置分类、报告复制和桌面保存覆盖行为。
- 已落实：识别 Windows 手动代理绕过规则，跳过匹配目标的手动代理请求，并在脱敏报告中说明原因。
- 下一批评估：历史摘要索引与超过 100 条记录的分页、环境变量代理路径，以及不泄露具体地址的 IP 类型提示。这些改动需要旧历史兼容和隐私回归测试。
- 多源公共 DNS、证书验证失败后继续发送 HTTP、虚拟网卡名称推断和浏览器式 User-Agent 不能作为默认诊断结论。若加入，应明确用户选择、实际探测路径与证据局限。
