# 0.1.0 源码预览版发布准备

## 定位

本版本供开发者和愿意反馈问题的用户试用。公开源码不等于发布正式安装包。诊断结果只是分层证据与可能原因，浏览器、系统代理和本机直连可能采用不同路径。

## 发布前检查

- [x] MIT 许可证、README 的预览版说明和安全问题报告方式。
- [x] 当前文件及全部 16 个 Git 提交的文件名和常见凭据模式初筛；模拟 HAR 为唯一命中敏感扩展名的历史路径，未发现常见私钥或令牌模式。自动匹配不能保证不存在其他隐私内容。
- [x] Go 测试、vet、前端检查及 Windows 桌面构建通过；见 [阶段 5 验证](verification-stage5.md)。
- [ ] 在桌面界面完成选择真实浏览器 HAR 并看到分析结果。
- [x] 在本机当前用户此前未安装 NetEvidence 的状态下，静默安装、启动、卸载均通过；卸载后安装目录和卸载注册表项消失，本机 16 份历史文件的 SHA-256 均未变化。
- [ ] 发布前处理历史提交中的个人邮箱，复查 Git 提交、README、示例和构建材料中的个人或机构信息。

安装验证使用现有 WebView2 的开发电脑，尚未在全新 Windows 系统验证运行时安装。HAR 页面和系统文件选择框可以打开，但自动化接口未能可靠操作该系统对话框，故不能把整个导入流程记为通过。

## 已知边界

- 当前安装包未签名，Windows 下载运行时可能出现 SmartScreen 提示；安装包暂不面向普通用户推广。
- 仅自动尝试 Windows 手动系统代理。PAC、浏览器扩展代理及其他浏览器网络路径不会完整复现。
- HAR 分析仅在内存中进行，限制为 20 MiB；请勿公开原始 HAR。导入结果是请求异常线索，不直接证明网络故障。
- 历史保存在当前用户的本机目录，含原始诊断数据；分享前请选择脱敏报告并预览。
